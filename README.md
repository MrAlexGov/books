# Books

Репозиторий для хранения и публикации наших книг.

## Структура

- `books/` — книги в формате Markdown.
- Каждая книга размещается в отдельной папке: `books/<book-slug>/`.
- Основной текст книги — `README.md` или отдельные файлы глав (`01-introduction.md`, `02-chapter-name.md` и т. д.).
- Материалы, изображения и дополнительные ресурсы книги хранятся рядом с её текстом.

## Формат

Тексты храним в UTF-8 и Markdown. Для каждой книги желательно добавлять краткое описание, автора и статус подготовки.

Новые материалы публикуем отдельными понятными коммитами.
