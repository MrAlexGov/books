# Скиллы книжной фабрики

Скилл — повторно используемая инструкция, описывающая задачу, входные данные, порядок действий, формат результата и критерии проверки.

## Каталог

- `01-audience` — определить и описать целевую аудиторию.
- `02-book-bible` — создать и поддерживать библию книги.
- `03-arcs` — разработать длинную и короткие арки.
- `04-chapter-architecture` — спроектировать карту и внутреннюю структуру глав.
- `05-chapter-drafting` — написать или продолжить отдельную главу.
- `06-editorial-continuity` — проверить текст, непротиворечивость и связь с каноном.

## Общий контракт скиллов

Каждый скилл должен:
1. Проверять, какие входные документы уже существуют.
2. Не выдумывать отсутствующие авторские решения и факты.
3. Отделять подтверждённые решения от гипотез и предложений.
4. Возвращать результат в заданном формате.
5. Указывать открытые вопросы, риски и влияние на другие документы.
6. Сохранять авторское право финального решения за автором.

Скиллы не заменяют друг друга: они выполняют отдельные этапы одного конвейера.
