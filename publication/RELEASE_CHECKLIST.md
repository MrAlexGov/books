# Чек-лист подготовки книги «ИИ для онлайн-школы» к публикации

**Текущий статус:** первый полный вариант рукописи собран. Публикация как законченного издательского продукта ещё требует редакторской, технической и правовой проверки.

## 1. Рукопись

- [ ] Проверить, что все 21 главы присутствуют в исходном каталоге.
- [ ] Проверить введение и заключение.
- [ ] Проверить все четыре приложения.
- [ ] Сверить оглавление с файлами.
- [ ] Пересобрать файлы в `manuscript/` после любых изменений исходников.
- [ ] Удалить технические заглушки, если они обнаружатся.
- [ ] Проверить нумерацию, заголовки и перекрёстные ссылки.

## 2. Литературная редактура

- [ ] Выровнять голос автора и обращение к читателю.
- [ ] Сократить повторяющиеся вступления и заключения глав.
- [ ] Устранить повторы между главами 5 и 12.
- [ ] Устранить повторы между главами 4 и 20.
- [ ] Развести общую архитектуру главы 3 и прикладные интеграции в главах 14–17.
- [ ] Проверить переходы между пятью частями.
- [ ] Проверить, что каждая глава решает собственную задачу.
- [ ] Проверить единый стиль таблиц, списков и схем.

## 3. Фактчекинг

- [ ] Открыть все внешние ссылки.
- [ ] Проверить актуальность документации GetCourse.
- [ ] Проверить документацию OpenAI API.
- [ ] Проверить ссылки и условия Make и n8n.
- [ ] Проверить примеры JSON и схем.
- [ ] Проверить кодовые фрагменты.
- [ ] Сверить результаты с [журналом технического фактчекинга](../research/TECHNICAL_FACT_CHECK.md).
- [ ] Проверить арифметику и единицы измерения.
- [ ] Проверить условные числа и обозначения примеров.

## 4. Право и безопасность

- [ ] Проверить применимость GDPR и российского законодательства.
- [ ] Сверить результаты с [журналом правового фактчекинга](../research/LEGAL_FACT_CHECK.md).
- [ ] Проверить разделы о несовершеннолетних.
- [ ] Проверить трансграничную передачу и поставщиков.
- [ ] Проверить оговорки об авторских правах.
- [ ] Проверить рекомендации по записи встреч и обработке аудио.
- [ ] Убедиться, что нет юридически категоричных универсальных советов.
- [ ] Убедиться, что все примеры с данными учеников синтетические или обезличенные.

## 5. Методическая и техническая рецензия

- [ ] Привлечь практикующего руководителя онлайн-школы.
- [ ] Привлечь методиста / преподавателя.
- [ ] Привлечь специалиста по интеграциям.
- [ ] Привлечь специалиста по защите данных или юриста.
- [ ] Зафиксировать замечания и решения по ним.

## 6. Издательская подготовка

- [ ] Утвердить название и подзаголовок.
- [ ] Утвердить аннотацию.
- [ ] Подготовить авторское описание.
- [ ] Определить формат и платформу публикации.
- [ ] Подготовить обложку.
- [ ] Подготовить макет электронной и/или печатной версии.
- [ ] Проверить оглавление и навигацию.
- [ ] Проверить ссылки и отображение кода в конечном формате.
- [ ] Указать дату актуальности технических сведений.
- [ ] Утвердить финальную версию.

## 7. Контроль версий

- [ ] Зафиксировать дату заморозки рукописи.
- [ ] Сохранить SHA или тег релизной версии репозитория.
- [ ] После редакторских правок пересобрать рукопись.
- [ ] Повторно проверить все части сборки.
- [ ] Не менять опубликованную версию без фиксации изменений.

## Принцип выпуска

Не называть книгу окончательно готовой к публикации только потому, что написаны все главы. Полный первый вариант текста — важная веха; редактура, фактчекинг, рецензирование и вёрстка — отдельные обязательные этапы.
